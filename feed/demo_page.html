How an answer is built

  1. The agent calls the feedIt has four calls and no other source. With dates it asks what is on. With no dates it asks when to go.
  2. The feed returns facts with proofEach item says how sure it is: a date that a page states, a date from a rule, or not confirmed.
  3. The agent selects for the guestIt says how many items the feed has, shows the ones that fit, and gives each source.
